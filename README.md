# AutoCAD 2D & 3D Projects | Civil Engineering

A collection of AutoCAD drawings, building plans, engineering drawing assignments, and 2D/3D drafting projects for learning and practicing Computer-Aided Design (CAD).

##  About the Repository

This repository contains AutoCAD project files and technical drawings related to architectural planning and engineering drafting. It serves as a reference for students who want to explore practical applications of AutoCAD and improve their technical drawing skills.

The collection includes residential building plans, a villa plan project, and engineering drawing assignments.

##  Tools and Technologies

- **Software:** AutoCAD
- **File Formats:** DWG, PDF, and other supporting files where available

##  How to Explore the Projects

1. Clone or download this repository.
2. Browse the folders to locate the drawings you want to explore.
3. Open compatible `.dwg` files in AutoCAD.
4. Review the PDF files for convenient viewing and reference.
5. Examine the drawing dimensions, layouts, layers, and drafting methods to understand how each drawing is organized.

##  Learning Objectives

- Understand the fundamentals of 2D drafting and 3D CAD.
- Practice architectural floor planning and building layouts.
- Improve technical drawing interpretation skills.
- Learn to organize and present CAD project files.
- Develop familiarity with standard engineering drawing workflows.
